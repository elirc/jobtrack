# 04 — Code Reading Gym

Active practice. Nothing in this module is read-only: annotate, trace, contrast, review.
Do these with the code open in another pane and *write your answers down* before checking.

| File | Contents |
|---|---|
| [01-annotation-drills.md](01-annotation-drills.md) | 8 real excerpts to annotate — inputs, invariants, failure modes |
| [02-trace-tables.md](02-trace-tables.md) | 5 traces to fill in step by step |
| [03-fake-code-contrasts.md](03-fake-code-contrasts.md) | 8 bad-vs-better pairs tied to real repo patterns |
| [04-review-katas.md](04-review-katas.md) | 8 fake PRs to review, graded blocking/important/optional |

Rules of the gym: predict before you verify; grade yourself with the rubrics; when you
miss, write one sentence about *why* you missed (wrong mental model? skimmed? didn't know
the API?). The miss-notes are the curriculum.
